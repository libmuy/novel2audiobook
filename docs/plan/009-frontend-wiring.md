# 计划 009：前端接入计划 008 的后端新接口

> 状态：已实现。只改前端（`web/static/`）和前端测试，后端一行没动。

## 接入内容
- **素材库页**（`#/assets`）：从只读名字列表升级为素材规格的增删改（`/api/asset-specs`）+ 生成状态徽章
  （未生成 / 规格已变更 / 占位音 / 已生成）。「生成」先走 `asset_gen` 预检确认，再提交任务，进度条订阅 SSE
  的 `task-update`；页面刷新/切走再回来会接上还在跑的任务；可取消（批次边界生效，见 008）。删除可选「同时删除已生成音频」。
  **没有试听**：后端还没有音频播放接口，不放一个点了没反应的播放器。
- **角色库**：左侧嵌套分类树（`/api/role-category-tree`，任何变更都是克隆 → 整树 PUT → 用响应覆盖本地）替换原来的扁平分类标签；
  角色表单的分类下拉是全部路径，**并保留「角色身上还挂着、但已不在树里」的分类**（显示为「未登记」），否则编辑这种角色会悄悄清掉它的分类。
  角色支持标签（表单里回车添加、卡片展示、标签筛选行用 `/api/role-tags` 计数）。删除分类的确认弹窗如实说明「角色保留原分类名」。
- **配音工作台**：分块编辑加「背景音/音效」下拉（选项来自已生成的素材词表），分块卡片有 `bgm`/`sfx` 小标记，批量条加「批量设置素材」
  （每项可选「不修改 / 清空 / 某素材」）。保存素材后**自动同步到 timeline**（`refresh-assets`；没跑过 TTS 时 404 静默跳过）。
  素材字段**只在真的改了才发送**：后端校验非空素材名必须存在，分块引用着已缺失素材、用户只改文字时不能因此保存失败；
  引用着缺失素材的分块，下拉里保留「xxx（缺失）」一项，不会一打开就等于清空。
  （计划 006 里「工作台不要暴露 sfx/bgm」的约束到此解除——素材流水线现在是通的。）
- **小说详情**：批量混音旁加「混音时叠加背景音/音效」开关（勾选才传 `params.with_assets`，不勾不传参数，让后端遵循
  `mixing.voice_only` 配置）；选中章节显示素材引用数、缺失素材警告、上次混音是纯人声还是叠加了素材（无记录时如实说「无记录」）、
  以及素材引用已变化需要重新混音的提示。
- **设置页**：`mixing.voice_only` 开关（界面上反过来问「混音默认叠加背景音/音效」）。
- 顺带修了上一轮换皮遗漏的问题：简单页面（小说列表/设置/素材库）内容贴着左边缘，加了 `page-pad` 容器；模态框内容过高时底部按钮被裁切，
  改为 body 内部滚动、页脚常驻；角色库的删除/新建用统一确认弹窗替换了原生 `confirm()`/`alert()`。
